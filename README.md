# `.github`

This repository powers the public GitHub organisation profile for **Central Church Bristol**.

The file GitHub shows on the organisation Overview is:

```
profile/README.md
```

Edit that file, commit, and push to `main`. The org profile updates shortly afterwards.

## Requirements

For the profile README to appear:

1. This repository must be named **`.github`**
2. It must be **public**
3. The README must live at **`profile/README.md`** (not the repo root)

The root README (this file) is only for people opening the repository itself.

## Editing the profile

1. Change `profile/README.md`
2. Preview the Markdown in your editor or on GitHub
3. Commit and push to `main`

To add a logo or banner, put the image in `profile/` and reference it from the profile README, for example:

```md
<img src="logo.png" alt="Central Church Bristol" width="120" />
```
